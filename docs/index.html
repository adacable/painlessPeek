Painless Peek

Painless Peek is a browser extension to make it easier to more safely view traumatic imagery.

It applies filters — blur, greyscale, hue rotation — to images on any page. The best option is the letterbox filter, which lets you view a small window of an image while leaving the rest filtered. You can inspect the detail on a building while leaving bodies in the foreground blurred.

This extension has had basic testing but may flash images before filtering them occasionally, and there may be edge cases which are not filtered. Please report issues on GitHub.

Installation

Firefox

Download the latest .zip from the releases page and load it as a temporary add-on via about:debugging.

Chrome

  1. Download and unzip the latest release from the releases page.
  2. Open chrome://extensions, enable Developer Mode (top right).
  3. Click Load unpacked and select the unzipped chrome-mv3 folder.

Usage

The popup appears when you click the extension icon. Each selector (e.g. "Images") has:

  • A peek dropdown — choose letterbox to reveal a small window under your cursor, or reveal to slowly unblur on hover.
  • Filter toggles — enable greyscale, blur, or hue-rotate, with sliders to control the intensity.

Known issues

  • Google Image Search intermittently breaks filtering.
